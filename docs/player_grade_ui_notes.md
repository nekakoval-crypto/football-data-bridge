# Player Grade UI notes

On the mirrored formation pitch, a future Match Card integration should show the player's shirt number and surname as today, plus a compact PBK Grade and confidence marker below. Manual replacements should be visually distinct and may show `Expected 7.4 → Manual 6.2` without implying a canonical probability change.

The manual configurator should reuse the same mirrored-pitch component for editing, not create a second tactical UI implementation.
